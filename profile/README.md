# ⚡ Welcome to m11s

M11S is an independent software studio building focused SaaS products, cloud-native infrastructure, and developer tooling — designed for real production systems, not demos.

---

## 🔧 What you'll find here

- **Helm charts** for self-hosted platform services — production-grade, published on [ArtifactHub](https://artifacthub.io/packages/search?org=m11s).
- **Terraform / OpenTofu providers** for self-hosted tools missing provider coverage.
- **Docker images** and container tooling for platform services.
- **Infrastructure modules** — Kubernetes, GitOps, and cluster bootstrap building blocks.
- **SDKs and automation** surfaced from real product operations when they prove durable.

---

## 🤝 How we work in the open

- We publish what falls out of running real products — open source is part of the studio ecosystem, not a side project.
- Documentation and clear contribution paths ship alongside the code.
- Issues and pull requests are welcome.
- Questions or proposals? Open a GitHub issue or reach out via [hello@m11s.io](mailto:hello@m11s.io).
