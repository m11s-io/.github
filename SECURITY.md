# Security

Do not include credentials, exploit instructions, or sensitive vulnerability
details in public issues or pull requests. If the affected repository offers
GitHub's private vulnerability reporting, use that feature. Otherwise, consult
the repository owner's published security contact or disclosure instructions.
Do not assume a private reporting channel is available where none is documented.

For suspected exposed credentials, avoid copying the value into an issue or
message. Identify the repository and location without reproducing the secret.
